# Screenshot aplikasi untuk landing page

Simpan screenshot asli dari aplikasi dengan nama persis seperti di bawah.
Selama file belum ada, landing page otomatis memakai mockup kode sebagai
cadangan sehingga tidak pernah tampil gambar rusak.

| File | Layar yang difoto | Dipakai di |
|---|---|---|
| `beranda.png` | Tab Beranda — performa sinyal + grafik + chart live | Hero, paling atas |
| `signal.png` | Tab Signal — daftar sinyal hari ini beserta hasilnya | Section "Isi satu sinyal" |
| `chat.png` | Tab Chat — komunitas | Section "Isi aplikasi" |
| `materi.png` | Tab Materi — daftar PDF edukasi | Section "Isi aplikasi" |
| `indikator.png` | Tab Indikator — indikator TradingView | Section "Isi aplikasi" |

## Wajib sebelum publish

- **`chat.png`: blur atau ganti nama anggota dengan inisial.** Screenshot asli
  memuat nama lengkap orang sungguhan beserta isi pesannya. Menerbitkannya di
  halaman publik tanpa izin mereka adalah masalah privasi, bukan sekadar
  masalah estetika.
- **`beranda.png`: sensor nama dan email pemilik akun** di bagian atas layar.
- Jangan potong status bar ponselnya — justru itu yang membuat screenshot
  terlihat asli, bukan render buatan.
