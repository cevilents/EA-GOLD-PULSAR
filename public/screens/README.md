# Screenshot aplikasi untuk landing page

Screenshot asli dari aplikasi. Format JPEG dipertahankan karena sumbernya
memang JPEG — mengubahnya ke PNG hanya memperbesar file tanpa memperbaiki
kualitas. Kalau salah satu file dihapus, landing page otomatis memakai
mockup kode sebagai cadangan dan tidak pernah menampilkan gambar rusak.

| File | Layar yang difoto | Dipakai di |
|---|---|---|
| `beranda.jpg` | Tab Beranda — performa sinyal + grafik + chart live | Hero, paling atas |
| `signal.jpg` | Tab Signal — daftar sinyal hari ini beserta hasilnya | Section "Isi satu sinyal" |
| `chat.jpg` | Tab Chat — komunitas | Section "Isi aplikasi" |
| `materi.jpg` | Tab Materi — daftar PDF edukasi | Section "Isi aplikasi" |
| `indikator.jpg` | Tab Indikator — indikator TradingView | Section "Isi aplikasi" |
| `ea.jpg` | Daftar EA yang bisa diunduh | Section "Isi aplikasi" |

## Wajib sebelum publish

- **`chat.jpg`: blur atau ganti nama anggota dengan inisial.** Screenshot asli
  memuat nama lengkap orang sungguhan beserta isi pesannya. Menerbitkannya di
  halaman publik tanpa izin mereka adalah masalah privasi, bukan sekadar
  masalah estetika.
- **`beranda.jpg`: sensor nama dan email pemilik akun** di bagian atas layar.
- Jangan potong status bar ponselnya — justru itu yang membuat screenshot
  terlihat asli, bukan render buatan.
